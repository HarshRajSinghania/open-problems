# Goals

One folder per UN Sustainable Development Goal, one sub-folder per target.
See the [goal table in the main README](../README.md#the-17-goals).

Folder names: `NN-goal-short-title/` and `<target code>-<short-slug>/`,
e.g. `06-clean-water-and-sanitation/6.3-water-quality/`. They are created by
[`tools/import_un_sdgs.py`](../tools/import_un_sdgs.py); please do not rename them by hand.
