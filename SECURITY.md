# Security policy

## Reporting a problem

Please **do not** report security problems in public issues.

Use GitHub's private reporting instead:
[Report a vulnerability](https://github.com/harrythentrepreneur/open-problems/security/advisories/new).
If that does not work for you, send a private message to the maintainer,
[@harrythentrepreneur](https://github.com/harrythentrepreneur).

Please include:

- what you found and where (file, tool, website page);
- how to reproduce it;
- what impact you think it has.

We will reply as soon as we can, keep you updated, and credit you if you
want.

## What counts

- Code in this repository (`tools/`, `site/`, `solution/` folders).
- The GitHub Actions workflows in `.github/workflows/`.
- **Personal data** that should not be here (names, contact details,
  locations of vulnerable people). Report it the same way; we will remove
  it. See [privacy and safety](how-we-work/privacy-and-safety.md).

## Supported versions

Only the `main` branch is supported.
