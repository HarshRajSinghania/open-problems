# Decisions

A short log of decisions that shape the project, so newcomers can see what
was decided and why. Add a new file for each decision:
`NNNN-short-title.md` (for example `0002-split-goal-06-into-own-repo.md`).

Template:

```markdown
# NNNN. Title

- Date: YYYY-MM-DD
- Status: proposed | accepted | replaced by NNNN
- Deciders: @handles

## Context
What problem were we facing?

## Decision
What did we decide?

## Consequences
What gets easier or harder because of this?
```
