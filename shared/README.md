# Shared

Code, data and docs that more than one goal or target can use, for example:

- a satellite-imagery download helper used by water (Goal 6) and forest
  (Goal 15) work;
- a common way to read the UN SDG API;
- shared design assets (no UN emblem or SDG icons, see
  [licensing](../how-we-work/licensing.md)).

## Rules

- Move something here only when **two or more** targets use it. Until then
  keep it in the target's `solution/` folder.
- One sub-folder per component, each with its own `README.md`
  (what it does, how to run it, who maintains it) and tests.
- Code here is Apache-2.0; docs are CC BY 4.0.
