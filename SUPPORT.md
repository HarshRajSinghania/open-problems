# Getting help

| You want to... | Go to |
|---|---|
| Ask a question, share an idea or say hi | [Discussions](https://github.com/harrythentrepreneur/open-problems/discussions) |
| Find a task | [Good first issues](https://github.com/harrythentrepreneur/open-problems/issues?q=is%3Aissue+is%3Aopen+label%3A%22good+first+issue%22) or the [catalogue](https://harrythentrepreneur.github.io/open-problems/) |
| Learn how to contribute | [CONTRIBUTING.md](CONTRIBUTING.md) |
| Report a mistake in a page or a tool | [Report a bug](https://github.com/harrythentrepreneur/open-problems/issues/new?template=03-report-a-bug.yml) |
| Report a security or privacy problem | [SECURITY.md](SECURITY.md) (privately, please) |
| Report behaviour that breaks our rules | [Code of conduct](CODE_OF_CONDUCT.md) |

Stuck on a task? Say so on the issue. Asking for help is normal here.

This is a volunteer project. We answer as fast as we can, but there is no
guaranteed response time.
